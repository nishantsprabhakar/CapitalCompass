# CapitalCompass Sale Data Room Checklist

## Product

- Live demo URL
- GitHub repo access
- Product screenshots
- Feature list
- Architecture overview
- Deployment guide
- Admin/payment workflow
- Deal pipeline workflow
- AI API integration notes

## Technical

- Source code
- Dependency list
- Render deployment blueprint
- Security posture memo
- Known limitations
- Roadmap
- Test/smoke evidence
- Generated sample DOCX/PPTX/XLSX outputs

## Commercial

- Pricing page
- Monetization model
- Buyer personas
- Pipeline of potential customers
- Pilot list
- Payment-link setup
- Any revenue or user metrics

## Legal / IP

- Ownership statement
- Contributor list
- Third-party dependency list
- Open-source license review
- Trademark/domain status
- Assignment documents if applicable

## Security / Compliance

- Data handling statement
- Local-first processing description
- Auth/session model
- Admin role controls
- Payment handling via hosted link
- Plan for managed database and audit logs
- SOC 2 / ISO roadmap

## Buyer Questions To Prepare For

- How many active users?
- How many generated diligence outputs?
- Is there revenue?
- Who owns the IP?
- What data is stored?
- Can it be deployed in a private VPC?
- Does it use third-party AI by default?
- How are uploads secured?
- How does it compare with AlphaSense, Datasite, PitchBook, and DealCloud?
- What work remains before enterprise deployment?
