# CapitalCompass Valuation and Deal Terms Memo

## Positioning

CapitalCompass should be sold as a strategic product/IP acquisition, not as a conventional revenue-multiple sale. The USD 2M+ value case depends on a buyer valuing time-to-market, domain-specific workflow IP, and integration with an existing dealmaker distribution channel.

## Valuation Target

- Minimum acceptable: USD 2M
- Preferred range: USD 5M to USD 10M
- Stretch case: USD 10M+ if a strategic buyer sees immediate product integration value

## Why USD 2M+ Is Defensible

CapitalCompass includes multiple components that would take a strategic buyer time and product focus to replicate:

- PE-specific diligence workflow
- File ingestion and corpus isolation
- Risk-led scoring algorithm
- Office-native document generation
- IC PowerPoint template support
- Sponsor-model generation
- Source-quality scoring and audit trail
- Admin console, premium gating, payment-link monetization
- Optional AI API support
- Deal pipeline module with Excel import and analytics
- Render deployment blueprint

## Strategic Valuation Logic

A buyer is not paying only for code. A buyer is paying to compress:

- Product discovery
- PE workflow design
- Document-generation edge cases
- IC memo/model output structure
- Vertical-specific scoring logic
- Early monetization shell
- Roadmap acceleration

If this saves 6 to 12 months of build time for a platform selling to PE, IB, corp dev, or data-room customers, USD 2M is a plausible strategic floor.

## Deal Structures

### Preferred: Clean Asset Sale

- USD 2M+ cash at close
- IP, code, brand/domain, product assets
- 30-90 day transition support
- Optional consulting agreement

### Higher-Upside: Cash Plus Earn-Out

- USD 1M to USD 2M upfront
- Earn-out to USD 5M+ tied to ARR, customer launches, or integration milestones
- Founder advisory role

### Defensive Backup: Exclusive License

- USD 250k to USD 500k upfront license
- Annual minimum guarantee
- Purchase option at USD 2M+ within 12 months
- Buyer-funded product hardening

## What Weakens Valuation

- No audited ARR yet
- No production SOC 2 / ISO evidence
- No Stripe webhook automation yet
- No managed database yet
- No confirmed enterprise customers yet
- No formal IP assignment/legal entity documentation provided in repo

## What Raises Valuation

- Signed pilots with PE/advisory teams
- Usage metrics: number of diligence runs, outputs generated, time saved
- Live payment conversions
- Buyer references
- Cloud deployment with enterprise auth and audit logs
- Data-room/CRM integrations
- Benchmarked output quality versus analyst work product

## Recommended Negotiation Anchor

Open at USD 7.5M to USD 10M for strategic acquisition. State USD 2M as the minimum floor only if pressed.

Suggested language:

"We are seeking the right strategic owner. A pure financial valuation is less relevant because this is a roadmap acceleration asset for PE workflow automation. We would prioritize a clean USD 7.5M strategic acquisition, but we are willing to discuss structure if the buyer can move quickly."
